# Правки после проверки владельцем — 25.11.2026

Только клиентский сайт. В общий шаблон переносить после одобрения.

- Цена справа в отдельной колонке max-content; текст слева, не пересекается с ценой. Зазор между колонками равен внутреннему отступу карточки справа. Варианты остаются под описанием, с общей колонкой точных цен. Сводная цена «от MIN ₽» сохранена.
- Все изменения команды из первой итерации отменены: исходные карточки, заголовки, разделы и данные. Не создавать направления вместо людей и не переименовывать портфолио.
- Описания и порядок галереи сохранены.
- Подсветка только «Смотреть работы»: плавная стационарная подсветка с внутренней тенью, 6 секунд, без сдвига или масштабирования. На кнопках открытия галереи добавленной анимации нет.
- Телефоны горизонтально: две колонки первого экрана, ограниченная ширина страницы, прокручиваемые окна с ограничением по высоте. Планшеты: ограниченная ширина текста и три колонки галереи. На больших мониторах максимальная ширина сайта 1920 px.
- Проверки: 320–1920 px; портрет/альбом телефонов и планшетов; Chromium и WebKit; отсутствие пересечений текста/цен и равенство отступов.
