# Проверка Бьюти Лаб — 25.11.2026

Изменения пока только в клиентском репозитории. В общий шаблон переносить после проверки владельцем.

- Закрытая карточка: название, описание, одна цена; диапазон отображается «от MIN ₽». Точные цены всех вариантов сохранены в раскрытии. Варианты используют общую колонку цены; отдельные слова не разрываются.
- Ширину, порядок и расстояния карточек, цвета и пропорции фото задаёт верстка. Данные не меняют эти правила. На экранах меньше 1024 px используется мобильная компоновка независимо от мыши/тачскрина.
- Имя: только имя без фамилии, без многоточия. Если исходник начинается с фамилии, заполнить firstName явно. Должности/стаж/квалификацию не выдумывать. Существующая подтвержденная специальность сохраняется; при отсутствии берётся короткая из словаря site-content.js.
- Словарь: ногти/маникюр/педикюр → Nail-мастер; окрашивание → Колорист; стрижки/волосы → Парикмахер; косметология → Косметолог; брови → Бровист; ресницы → Lash-мастер; перманент → Мастер перманента; макияж → Визажист; массаж → Массажист; эпиляция → Мастер эпиляции.
- Связанные serviceIds/work имеют приоритет, включая явные пустые списки. При отсутствии этих полей услуги берутся по подтвержденным categories мастера. Общие фото категории подписываются «Работы салона», а не личное портфолио.
- Если людей нет в источнике: карточки направлений с услугами/работами салона. Не создавать имена, стаж, отзывы или фотографии сотрудников.
- Галерея: «Салон» первым в списке; открытие с первой непустой категории работ. Если других нет — доступная категория. Если салона нет — первая категория.
- Описания чистятся при подготовке, без вызовов ИИ на сайте. Исходный business.json не изменяется. Незавершённый хвост удаляется до границы предложения; если хвост содержит условия/цену/ограничение, фрагмент скрывается и попадает в DESCRIPTION_REVIEW.json. Не дописывать обещания, состав услуги или результат. Перевод сохраняет факты.
- Блики раз в 6 секунд только в видимой области; появление блоков один раз. Учитывается prefers-reduced-motion.

Проверка: статическая валидация; Chromium/WebKit; ширины 320, 360, 375, 390, 414, 430, 768, 1180, 1366; русский и английский; цены, запись, галерея, профили, переход назад.
